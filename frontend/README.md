# yozigo frontend

React + TypeScript + Tailwind CSS client for the yozigo movie ticket booking app.

See the root [`README.md`](../README.md) for full setup instructions, seeded accounts and the list of completed flows.

## Quick start

```bash
npm install
cp .env.example .env
npm run dev
```

## Scripts

| Script | Description |
|---|---|
| `npm run dev` | Start the Vite dev server on `http://localhost:5173` |
| `npm run build` | Type-check and build for production |
| `npm run preview` | Preview the production build locally |
| `npm run lint` | Run oxlint |
